# مشروع متجر HJY LAB (النسخة الحديثة - Jamstack)

هذا المستودع يحتوي على الواجهة الأمامية للمتجر الإلكتروني `HJY LAB`، والتي تم إعادة هيكلتها وتطويرها باستخدام معمارية **Jamstack** الحديثة لتوفير أداء فائق، حماية أعلى، وتجربة مستخدم ممتازة.

## 🚀 التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** HTML5, Tailwind CSS, Vanilla JS.
- **إدارة البيانات:** ملفات CSV (عبر مكتبة PapaParse).
- **الاستضافة والنشر (Hosting & CI/CD):** Cloudflare Pages للواجهة مع ربط مباشر بـ GitHub للتحديث التلقائي (Continuous Deployment).
- **الواجهة الخلفية وقاعدة البيانات (Backend & DB):** Cloudflare Workers + D1 SQL Database (مخصصة لنظام تقييمات العملاء).
- **معالجة الصور:** تقنية التحميل الكسول (Lazy Loading) باستخدام صور مصغرة `thumb_` وصيغ حديثة (WebP).
- **الأمان:** Cloudflare Turnstile Captcha لحماية النماذج من البرمجيات الخبيثة.

## 📁 هيكلية المشروع
تم ترتيب المجلدات والملفات ليكون المشروع قابلاً للتوسع وسهل الإدارة:

## ⚙️ كيف يعمل النظام؟
1. **قراءة البيانات:** عند تحميل `index.html`، يتم جلب ملفات الـ CSV من مجلد `data-csv` وقراءتها باستخدام `PapaParse` لتخزينها في مصفوفات (Arrays) داخل المتصفح.
2. **البحث (Fuzzy Search):** توفر خوارزمية البحث المدمجة تطابقاً تقريبياً (تقسيم الكلمات إلى مقاطع) مما يعطي نتائج قريبة جداً حتى لو أخطأ المستخدم بكتابة حرف أو حرفين، ولا يظهر صفحة "لا توجد نتائج" إلا نادراً.
3. **التنقل (Routing):** النظام عبارة عن تطبيق صفحة واحدة (SPA) يعتمد على الهاش `#` في شريط العنوان للتنقل بين الأقسام، المنتجات، صفحة الدفع، والأسئلة الشائعة دون إعادة تحميل الصفحة.
4. **عربة التسوق والطلب:** يتم تجميع المنتجات، حساب التكلفة (مع خيارات الطلب المستعجل ورسوم الشحن)، ومن ثم إرسال التفاصيل كرسالة منسقة إلى واتساب/تيليجرام.
5. **الفيديوهات والصور:** تعتمد على ملفات CSV مقسمة كالتالي:
   - **ملف الفئات (`*_categories.csv`):** الصف الأول يحتوي على أسماء الأقسام، والأعمدة تحتها تحتوي على الأرقام التسلسلية (`#`) للعناصر التابعة لها.
   - **ملف القائمة (`*_list.csv`):** يحتوي على 3 أعمدة: `url`، `name` (أو `title` للفيديوهات)، و `#` (رقم تسلسلي).
     - *ملاحظة:* للصور، يمكنك كتابة مسار الصورة محلياً في عمود `url` (مثل `sham-cash.png` أو `img/photo1.jpg`).

## 🛠️ التحديث والنشر عبر لوحة التحكم (admin/index.html)

### تشغيل لوحة الإدارة محلياً (بيئة معزولة)
- **اختصار واحد فقط: «HJY Admin».** يشغّل كل شيء (البيئة الافتراضية + الخادم + نافذة التطبيق) مع **بدون أي نافذة cmd**، وعند إغلاق نافذة التطبيق يتوقف كل شيء تلقائياً وفوراً (الخادم والعمليات التابعة). لا يوجد اختصار إيقاف منفصل.
- `admin\start_admin.bat` للطوارئ والتشخيص فقط (يُظهر نافذة الأوامر وسجل الأخطاء).
- **عند نقل المشروع إلى حاسوب جديد أو تغيير إصدار Python:** لا تنسخ `admin\venv` أبداً — إنها مرتبطة بمسار Python في الجهاز القديم. احذفها وشغّل `admin\setup_env.bat` مرة واحدة، أو اترك اختصار «HJY Admin» يعيد بناءها تلقائياً. هذا هو كلام المطوّر السابق وهو صحيح.
- كل شيء معزول داخل المشروع: `admin\venv` للبايثون، و`admin\.runtime` للسجلات والملفات المؤقتة وذاكرة pip وملف تعريف المتصفح. لا يتم تثبيت أي شيء في نظام Windows.
- إعدادات GitHub (Token + Repo + Branch) تُحفظ في `admin\github-settings.json` داخل المشروع (غير مرفوع إلى Git)، فلا تضيع عند نقل المجلد.
- لفحص سلامة البيانات (فهرس المنتجات، فهارس الصور `photo` و`customer_photo`، أسماء الصور، ملفات about/QA، أيقونات PWA): شغّل `admin\check_data.bat`.
- سجل الصيانة والتعديلات المرجعي: **`PROJECT_LOG.md`** — راجعه قبل أي تحسين جديد وأضف إليه ما فعلته.

- **البحث أصبح عامًا:** البحث من أي قسم يبحث في كل المنتجات، وليس داخل القسم المختار فقط.

- **الاسم الثلاثي إجباري** عند اختيار «الشحن».
- **زر «تواصل معنا على الواتساب»** في الشريط العلوي.

### تحديثات لوحة الإدارة (2026-11-06)
- **تبويبات واضحة:** المنتجات، الأقسام، الشحن، صفحات الموقع، الصور والوسائط، الإعدادات.
- **إدارة الشحن المتقدمة:** إضافة/تعديل/حذف شركات ومحافظات وفروع، ملاحظة لكل فرع، وترتيب أولوية بالأسهم.
- **ترتيب المنتجات داخل كل ملف CSV** بالأسهم، ويُحفظ بنفس ترتيب ظهوره في الموقع.
- **شريط تنسيق ABOUT2 والأسئلة الشائعة:** غامق + ألوان.
- **صورة ثانوية تلقائية:** إذا كانت `CODE` مفقودة و`CODE-1` موجودة، تُعرض الثانية تلقائيًا.
- **بيانات الشحن** في `data/governorates.csv` و`data/carriers.csv` و`data/branches.csv` (الأخير: `company;governorate;branch;note`) — ترتيب الأسطر هو ترتيب الأولوية.

تم توفير لوحة تحكم بسيطة ومدمجة بملف **`admin/index.html`** تعمل كواجهة أمامية فقط (Client-side) للاتصال بـ GitHub:
1. **الوصول للوحة:** استخدم اختصار سطح المكتب «HJY Admin» (أو `admin\start_admin.bat` للطوارئ) ثم رابط `http://localhost:8333/admin/index.html`.
2. **إعدادات GitHub:** ضع الـ `Token` الخاص بحسابك على GitHub مع اسم المستودع (مثال: `username/HJY-LAB-WEB`) واضغط "حفظ الإعدادات".
3. **محرر البيانات الشامل:** من خلال القائمة المنسدلة، يمكنك اختيار أي ملف CSV في الموقع (المنتجات `cell-bms.csv`، العروض `hot-price.csv`، منتهي الكمية `out_products.csv`، الأقسام `categories.csv`، والفيديوهات والصور).
   - يمكنك تعديل الحقول مباشرة داخل الجدول.
   - يمكنك حذف سطر أو إضافة سطر جديد.
   - عند الانتهاء، اضغط "حفظ التعديلات في GitHub" ليتم رفع الملف مباشرة، وستقوم Cloudflare بتحديث الموقع للجمهور خلال ثوانٍ.
4. **ضغط واقتصاص الصور:** تحتوي اللوحة على أداة لرفع صورة، اقتصاصها بنسبة `1:1` وتحويلها إلى صيغة `WebP` خفيفة جداً لتحميلها وإضافتها للمستودع لاحقاً.
