إدارة الفئات الفرعية (Subcategories)

فئة أساسية ← فئة فرعية ← أكواد المنتجات. تُحفظ في SubcategoriesA.csv و SubcategoriesB.csv (مع الفئات الأساسية الثلاث في categories.csv).

إدارة الفئات والملف الموحد (categories.csv)

3 أعمدة ثابتة (منتهي كمية / رائج / صفحة رئيسية) + أعمدة الفئات ديناميكية — كل عامود يحتوي على أكواد المنتجات المصنفة تحته

تعليمات الملف الموحد:
أول خلية في كل عامود = اسم الفئة أو التصنيف
جميع الخلايا تحت اسم الفئة = أكواد المنتجات (CODE) التابعة لهذه الفئة
يسمح بتكرار نفس الكود في أكثر من فئة
لا يمكن حذف أو تغيير اسم الأعمدة الثلاثة الثابتة: منتهي كمية، رائج، صفحة رئيسية

إعدادات الصفحة

عرض الواجهة
إخفاء عمودي رأس المال (H) والربح (P) عند تصفح الواجهة فقط (يظهر سعر البيع PRICE).
المزامنة المحلية (مجلد المشروع)
اربط مجلد HJY-LAB-WEB المحلي ليتم كتابة كل تعديل فيه تلقائياً (CSV + الصور) بعد كل نشر.
غير مرتبط
يتطلب Chrome/Edge. ستُطلب إذن الوصول للمجلد مرة واحدة.
